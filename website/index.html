04 — file share

把文件丢到
同一张网里。

不用微信压缩包，不用网盘中转。shrinkdrop 在电脑上开一个本地服务，同一 Wi-Fi 下的手机、平板、另一台电脑直接打开链接。

  • 目录浏览 + 搜索 + 实时刷新，新丢进去的文件马上出现在列表里。
  • 可收可发：允许访客上传后可接收文件；文件夹上传需在设置中单独开启，并使用支持目录选择的浏览器。
  • 随时停止：点一下释放端口，旧链接立即失效，不留后台服务。
  • 本地账号：账号只保存在这台电脑的设置里，用来分配下载、上传和发文字权限；不需要注册云账号，也不同步到其他设备。

06 — questions

大家常问的几件事。

压缩后的图片会上传到哪？

会通过 HTTPS 上传到 TinyPNG、TinyJPG 或 Tinify 的匿名压缩服务，结果随后下载回本机。客户端不需要 API Key，也不启动自建服务器；厂商侧的处理和保留规则以其政策为准。

分享文件也会经过云端吗？

不会。分享由电脑上的本地服务提供，访问者和电脑在同一局域网内直连，文件不经过任何云中转。停止分享后端口立即释放。

支持多大的图片、多少张一起压？

支持 PNG、JPG、WebP，单张不超过 20 MB，宽高各不超过 32,768 像素，总像素不超过 6,400 万；并发数可在 1–5 之间调整，超出并发的任务会排队。

覆盖会改坏原图吗？

覆盖前会二次确认，并校验原图是否被其他程序修改、移动或设为只读；任一情况都会阻止覆盖。确认成功后才会写回，且无法撤销。更稳妥的做法是保存副本。

访客能在分享页里预览文件吗？

可以。图片、音频、视频和支持的文本文件都能在条目下方展开预览；音频支持拖动进度、前后 15 秒和倍速播放，长文本折叠后按需展开。

需要账号或云同步吗？

无需云账号，也没有云同步。局域网分享可选用本地账号控制访问权限；应用没有历史记录数据库，退出后会清理本机临时结果。
