# 前端对 ui 设计问题的答复（瞌睡虫）

对应 `docs/design/README.md` 里给前端的 7 个问题。

1. **样式方案**：扩展现有 `src/styles/tokens.css`，不引入 Tailwind。设计规范里的颜色、字体、间距都落成 CSS 变量，浅色和深色两套。
2. **组件库**：单选组、弹窗、对比滑块用 Reka UI（无样式组件），样式全部走我们自己的 token。
3. **部分成功**：前端在 store 里推导，不改 Server 状态机，已确认。推导用 `@tinypng/shared` 的 `deriveDisplayStatus()`。另外新增展示状态 `output-failed`：有处理结果但所有输出都失败，文案“已处理，保存失败”，只给“重试输出”按钮，并提示没有消耗额度。`failed` 只表示 Provider 处理失败。只要已有结果且有输出失败，就显示“重试输出”（scope `outputs`），跟推导出的状态无关。
4. **处理中加图**：允许。新加的图片默认是草稿，“开始处理 (n)”只统计草稿数。
5. **保存位置**：Tauri 记住上次选择的目录，并提供“更改”入口；Web 用浏览器下载。
6. **连接中断**：Server 每 15 秒发一次心跳。超过 30 秒没收到任何事件就显示“连接中断”并自动重连，重连成功后重新拉一次完整批次状态，提示随之消失。
7. **切换到本地模式**：同意。切换时移除 URL 草稿，用 toast 提示移除了几张。
