# 隐私说明

图片会通过HTTPS直接上传到TinyPNG、TinyJPG或Tinify的匿名网页压缩服务，处理结果随后下载到本机。「上传自动压缩」默认关闭：关闭时，导入图片需手动点击开始；开启时，现有待开始图片和之后新导入的图片会自动上传压缩。此开关仅在本次应用会话有效。

客户端不需要API key，也不启动自用Server。网络只由Rust原生层访问固定厂商站点，前端不接受任意下载地址。

原图路径、内容摘要与临时结果保存在本次应用会话的Rust状态中，页面使用文件ID。任务没有持久化数据库或历史列表，退出窗口会取消处理并清理本机临时结果。

保存由用户选择目标位置，生成副本；覆盖原图则每次先弹窗确认，再将压缩结果写回其对应原始位置。覆盖前会校验原图内容，原图被外部修改后不会直接替换；确认覆盖成功后无法撤销。取消保存或覆盖会保留处理结果，可以稍后重试。图片在厂商侧的处理和保留规则以厂商政策为准。

图片会上传至 TinyPNG 进行压缩；除非手动覆盖，原图不会被修改。
