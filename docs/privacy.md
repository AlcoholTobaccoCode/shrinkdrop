# 隐私说明

## MVP

图片默认只在当前设备内读取、解码、压缩和写入临时结果。项目不把原图发送到 Tinify、TinyJPG 或其他第三方服务。桌面端文件真实路径保存在 Rust 侧状态，Vue 渲染层只接收不可逆文件 ID。

## Web 限制

浏览器只会处理用户主动选择或拖入的文件。浏览器无法安全地覆盖原图，因此 Web 端提供下载和图片剪贴板能力；用户关闭会话后会释放临时 Object URL。

## 后续云 Provider

任何云压缩 Provider 必须单独说明上传对象、保存时间、鉴权方式、失败重试、限流和删除策略。密钥不得进入 Web bundle，也不得继续调用旧项目的 `/backend/opt/shrink` 内部路径。
